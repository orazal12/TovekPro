TovekPro V2.8 builds on Tovek V2.7 with major readability, semantic naming, OOP method recovery, control-flow, and formatting upgrades — plus a one-flag `--pro` / `PRO` preset for clean, human-readable Luau output.

Highlights
- New `--pro` CLI flag and `X-Decompile-Flags: PRO` server/WASM/Roblox client preset combining `compact_style`, `assume_standard_libraries`, `assume_no_nan`, and `clean_comments` (default mode stays 100% compatible with upstream semantics).
- New `--clean-comments` / `CLEAN_COMMENTS` option to omit `-- inferred equivalent call`, helper counts, and diagnostic comments while keeping `--!native`.
- Measured across 7 real Roblox scripts (Beacon, ClickToMoveController, Promise, Signal, SpawnShield, Store, Trove):
  - Generic locals (`v*`): 582 -> 208 (-64.3%; Promise -77.4%, Store -88.5%, Signal -67.4%, Trove -100%)
  - Generic parameters (`p*`): 86 -> 73 (-15.1%)
  - Recovered OOP colon methods (`:fn`): 81 -> 108 (+33.3%; ClickToMoveController 24 -> 48)
  - `not (a < b)` NaN guards (`--pro`): 2 -> 0 (-100%)
  - `-- inferred` diagnostic comments (`--pro`): 79 -> 0 (-100%)
  - Overlong lines (>120 columns, `--pro`): 14 -> 5 (-64.3%)

Semantic naming & OOP method recovery
- Added 15+ Roblox event callback signatures (`Chatted`, `TouchTap*`, `MoveToFinished`, `HealthChanged`, `StateChanged`, `AttributeChanged`, `FocusLost`, `Mouse*`, etc.).
- Class name recovery from `__className`, `ClassName`, and metatable error messages; `--script-name` support for subclasses (`setmetatable({}, Base)`) and wrapper exports (`return { new = Class.new }` / `table.freeze({ ... })`).
- Rich Luau/Roblox idiom naming: `select("#", ...)` -> `argCount`, `{ ... }` -> `args`, `task.wait()` -> `dt`, `os.clock() - t` -> `elapsed`, vector deltas, `ValueBase.Value`, `rawget`, `newproxy`, `JSONEncode`/`JSONDecode`, `FindFirst*OfClass`/`WhichIsA`, multi-return tuples (`coroutine.resume`, `string.find`, `FindPartOnRay*`, `:await()`), metamethod/setter/predicate params (`__index`, `__newindex`, `SetFoo`, `.is`), and vector `.X/.Y/.Z` parameters.
- Second-pass class-consistency OOP method recovery with per-prefix static dot-call scoping, constructor-table field harvesting, and `.prototype` member recovery.

Control flow, expressions & formatting
- Positive equality guard merging emits `if a == 1 or a == 2 then` instead of double-negated `if not (a ~= 1 and a ~= 2) then`.
- Expands single-closure `cond and function(...) ... end or fallback` back to clean `if/else`.
- NaN-safe De Morgan in guard negation, multi-arm boolean `if/elseif/else` short-circuit folding, terminal `else` lifting after returning guards, windowed liveness in `copy_cleanup`, clean forward declarations for self-capturing connections and branch-initialized locals, exact `Vector3` named constants (`Vector3.zero`, `one`, `xAxis`, `yAxis`, `zAxis`), and improved line wrapping for long binary arguments and `and`/`or` chains.

Downloads: Windows x86_64, Linux x86_64, Linux aarch64, and macOS (Apple silicon).
Each package contains `luau-lifter` (CLI), `web-server` (local HTTP server), and `LICENSE.txt`. `SHA256SUMS.txt` lists the checksums.
